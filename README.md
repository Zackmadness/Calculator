# 🧮 Calculator

A fully functional, browser-based calculator built as the final capstone project for [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

## Live Demo
[View Live Project](https://zackmadness.github.io/Calculator/) 

## 📖 Overview

This project is a feature-rich calculator application designed to replicate the functionality of a standard calculator while reinforcing core JavaScript concepts such as state management, DOM manipulation, event handling, and keyboard interactions. All calculations are handled through custom logic without relying on `eval()`.

## ✨ Features

- ➕ **Core Arithmetic Operations** – Addition, subtraction, multiplication, and division.
- 🔄 **Chained Calculations** – Supports continuous calculations without resetting state.
- 🎯 **Full Keyboard Support** – Use number keys, operators, Enter, Backspace, and Escape.
- 🔢 **Decimal Handling** – Prevents multiple decimal points in a single number.
- ⌫ **Delete Functionality** – Remove individual digits using the `DEL` button.
- 🚫 **Division by Zero Protection** – Displays an error and resets the calculator safely.
- 📏 **Rounded Decimal Results** – Handles floating-point calculations cleanly.
- 🌙 **Modern Dark Theme** – Styled with a Catppuccin-inspired UI and responsive button interactions.
